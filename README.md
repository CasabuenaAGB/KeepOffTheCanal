# KeepOffTheCanal
Tower Defense Game

Project description:
This project is a tower defense game, where you defend a body of water, namely a river, from trash enemies, making sure it does not lose cleanliness

Important features:
Base Health (River Cleanliness)
Boolean Placement (Certain places where the towers could be placed)
Tower Placement (where you can place towers to attack enemies)
